# 从品牌特征出发设计动作

> 参考片的主角几乎都是**手绘感的卡通角色、插画**（粗黑线、简单填色），在真实场景里演一个小故事。
> 企业 logo（尤其是几何图形标）很难做出这种味道。品牌有吉祥物、人物标、插画就优先用它们；只有字标时，配一个和品牌有关的小角色或插画一起演。

参考片好看，是因为每段动画都在讲这个品牌：咖啡店的猫在倒咖啡，面馆的小孩在吸面、冒热气，抹茶店的小人抬着茶碗走路。不要把 logo 生硬地套一个弹出就交差。

## 最重要的一条：目的先行，出现要有原因
- 每一段先写**这个品牌要让人记住的一件事**（卖什么、什么承诺、什么氛围）。
- 主角的动作就是把这件事**演出来**：抹茶店就抬着一碗抹茶走进来，面馆就呼噜呼噜吸面，外带咖啡就让杯子自己赶路。
- **每个东西出现都要有原因**：被谁带来、被什么触发（热气变成字、喝完说出店名、门拉到底才笑）。写节拍表时每一行都加一列「为什么出现」，答不上来就删掉。
- 品牌名一般放在动作之后，当**落款**。
- 不要先挑一个好看的动法再往 logo 上套（拍扁、滚硬币、像素拼出），那样就是为了展示而展示。
- 节拍表先给用户确认，再做画面。

## 第一步：写三行品牌卡
1. **卖什么、在哪里出现**：咖啡店、面馆、AI 网站、服装品牌……
2. **性格**：可爱、高级、街头、科技、复古……性格决定节奏（可爱用弹跳，高级用慢、少）。
3. **图形里的标志性元素**：logo 里有没有可以单独做戏的部分，比如角色、杯子、∞、小方块、热气、星星。

## 第二步：用一句话写每段的动作
先写一句看得见的动作，再去挑动法，不要倒过来从动法清单里凑。例子：
- 「∞ 被一道光一笔绕出来，再点亮整排字」——AI 网站，表达无限生成
- 「logo 由像素块飞来拼成，.ai 像输入 prompt 一样打出来」——AI 生成感
- 「卷帘门拉下来，门落到底 .ai 才冒出来」——载体触发
- 「猫画出来后，壶嘴开始冒热气」——咖啡
- 「立体字一个个落到前台墙上，最后金属反光扫过」——高级办公室

## 第三步：挑场景和材质
- 场景挑品牌真实会出现的地方：AI 公司是前台墙、LED 大屏、周边帆布袋、霓虹灯牌；餐饮是招牌、菜单、橱窗、外卖袋。
- 材质跟场景走，见 `forms.md`：夜景用霓虹，户外大屏用 LED，玻璃用白边贴纸，办公室用立体字，黑板用粉笔，布料用盖章印刷。

## 第四步：一条合集里要有变化
- 每段换一种**场景 + 材质 + 主动法**的组合，昼夜、远近、冷暖也要交替。
- 开头一段用最有冲击力、最能代表品牌的那个（AI 品牌就用像素拼出）。
- 收尾用一个有「结束感」的动作，比如门关上、灯全亮。

## 动作家族（来自参考片）
| 家族 | 顺序 | 要点 |
|---|---|---|
| 落地回弹 | 下落 → 接触压扁 → 弹起 → 衰减 | 接触那一帧对准音效；压扁时横向变宽 |
| 探头 | 被遮住 → 露出到眼睛 → 停一下张望 → 整个蹦出来 | 一定要有遮罩边（窗框、门框）；停住时窗沿刚好在眼睛下沿 |
| 载体触发 | 门拉下 / 灯通电 → 到位 → 图形做出反应 | 图形跟着载体动，载体到位后才反应 |
| 通电 / 点亮 | 一段段闪烁 → 常亮 → 小闪光 | 霓虹、LED 最合适 |
| 使用产品 | 拿起 → 靠近 → 喝 / 吃 → 放回 | 两种做法：几张对齐的姿势图（看着杯子 → 喝 → 满足）一帧硬切；或者分层 SVG，让手、杯子单独动（`rig.md`）。再配点缀（热气） |
| 整版微动 | 版面一开始就在 → 主角做一个动作 → 小装饰跟着回应 | 不一定要从空白长出来，用 `static` + 点缀 |

## 做不了的要说清楚
现在代码能做的：换表情、眨眼（姿势图硬切）；跑步、走路的腿（橡皮管腿、街头走路小怪）；两三个角色互动（jump-react，各演各的、错开几帧）；落地的卡通烟尘（`dust`）；镜头缓推、横移、往上摇（street-crowd）。

还要靠 AI 视频的：3D 角色、真正的液体流动、真实的烟雾、镜头转动带出的透视变化、真人的动作（真人走动先用图生视频出一段固定机位的底片，再交给代码）。跟用户说明，不要硬凑。
