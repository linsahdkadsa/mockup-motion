# 桥段模板（14 个，都从参考片临摹出来，节奏是逐帧量过的）

```bash
mm new <模板名> <新场景文件夹>      # 复制模板配置（一般是 scene.json；包装模板是 package.json，scribble-pop 是 params.json），列出要准备的素材
```
主题不限：品牌、门店、活动、节日、个人 IP、产品上新、一句文案都行。模板只决定「怎么演」，演什么由你的小故事决定。

每个模板的结构都是：**出场（变出来）→ 停顿（有小动作）→ 一个快动作或反应 → 循环到结尾 → 字当落款**。

## 下面 6 个是第一批临摹的

## peek 窗沿探头（MACK'S）
- **故事**：角色从窗沿、桌沿、屏幕边慢慢探出头，张望一下，突然蹦出来做一个表情，店名在窗上方的招牌上逐字弹出。
- **适合**：新店开业、新品偷看、节日惊喜（「猜猜我是谁」）、个人 IP 打招呼。
- **场景**：一个有边框的表面（窗户、橱窗、电视屏幕、相框），**上方最好有一块空白招牌板**放店名（提示词见 `base-prompts.md`）。窗户要占画面一半左右，太远就先 `mm frame` 裁近。
- **素材（文件名照模板写，都从同一张基础图改，画布一样大）**：
  - `look_l.jpg` 张望：**中性表情**（闭嘴、不笑、不脸红），眼睛往一边看、头跟着偏一点。
  - `look_r.jpg` 往另一边看：把 `look_l.jpg` **整张画布**水平翻转另存（任何修图软件都行），不用另出图。只翻角色、或者角色不在画布正中，换姿势时角色会左右跳。
  - `mid_hands.jpg` 中间画：照原片画「眼睛睁大往上看、嘴是小 o、两只手已经举到脸两侧」，不要「手抬到一半」（AI 画不出真的一半）。
  - `cheeks.jpg` 最终表情：大笑 + 捧脸 / 比心 / Boo!。笑、腮红、手都留到这一张才出现，蹦出来才有新东西。
  - 提示词注意：角色在窗户**里面**，不是贴在玻璃上，**不要**写 white sticker border，否则底边被窗沿切平、三边却有白边，说不通。
- **节奏**：空 0.35 秒 → 0.6 秒露出 → 停 0.9 秒左右看 → 0.11 秒蹦出、过冲 16% → 回弹两次稳住 → 2.23 秒店名逐字弹出 → 角色一直轻晃到结尾（5 秒，落款停约 2 秒）。
- **摆位（模板默认）**：角色 `place` 宽 0.95、高 1.2、`anchor [0.5, 0.76]`，填满整扇窗，稳住时下面约 30% 藏在窗沿后面。
  - 藏得够深，蹦出的过冲才不会把底边带出来；引擎会自动把过冲限制在「底边刚好不露」以内（藏得浅，过冲就会被压小，蹦出没劲）。
- **`rise`**（默认 0.58）：停住时露出的部分 ÷ 蹦出稳住后露出的部分。验收：停住那一帧，**窗沿刚好在眼睛下沿**——眼睛看得见（张望才看得出），嘴和手看不见（蹦出才有笑点）。角色眼睛长得高就调小，长得低就调大。
- **店名**：第二块图形贴在招牌板上（单独一个 `surface`），用字标图（`mm decal 字标原图.png --color 招牌对比色 --out 场景/wordmark.png`；输入别直接用 `场景/wordmark.png`，同名会另存成 `wordmark_decal.png`，模板读不到），逐字弹出。不要和角色挤在同一块玻璃上——那样角色只能缩小，窗户上方的招牌板反而空着。
- 表面 `quad` 的下边就是窗框下沿，角色靠它遮住。

## draw-sign 一笔画出（COFFEE CLUB）
- **故事**：招牌上先画出主角在做一件事，然后店名弹出、口号打出，主角眨一下眼。
- **适合**：店招、logo 展示、菜单、手写海报、个人签名。
- **场景**：挂牌、墙面、海报。
- **素材**：线稿插画（主角闭眼 + 睁眼两张，其他不动），字单独一张或直接用 `text`。
- **节奏**：插画 0.3 秒画完 → 停 0.8 秒 → 标题每 0.04 秒一个字 → 小字打出 → 主角睁眼看一下。

## drip-run 滴落成形 + 原地跑（IN A RUSH）
- **故事**：一滴东西落下，变成角色，长出腿开跑；名字跟着跑冒出来。
- **适合**：外卖、快递、「赶时间」、限时活动、运动、所有「快」的主题。
- **场景**：大玻璃、白墙。
- **素材**：一个没有腿的物件角色（杯子、盒子、包子……），腿由代码画（`hose`）。
- **节奏**：滴落 0.2 秒 → 落地长腿 → 停 0.4 秒 → 原地跑 5 帧一步 → 名字每 0.045 秒一个字。

## outline-loop 描轮廓 + 循环（MOGU）
- **故事**：先描出角色外轮廓 → 填色 → 出细节 → 角色开始重复做一件享受的事（吸面、喝、啃、睡）。
- **适合**：餐饮、饮品、「好吃到停不下来」、氛围类。
- **场景**：深色玻璃（白线最好看）、黑板。
- **素材**：静止姿势 1 张 + 循环姿势 2 张（吸面 A/B）。
- **节奏**：描轮廓 0.45 秒 → 填深色 → 出细节（共 1 秒）→ 循环每 5 帧换一张 → 头边小卷线 → 店名每 0.1 秒一个字。
- **关键参数**：`"enter": {"motion": "outline", "seed": "bottom", "bandColor": "#ffffff", "fillColor": "#1c2350"}`

## jump-react 跳进来 + 反应（FU YUAN）
- **故事**：角色从画外跳进来落地 → 一个东西（招牌、产品、礼物）飞进来 → 角色吓一跳 → 聊起来、笑起来。
- **适合**：两个人或一群人的 IP、老店、朋友聚会、「发现新东西」。
- **场景**：店内透过玻璃、墙面。
- **素材**：跳、落地蹲、中间画（起身）、站、吓一跳、中间画（平静下来）、聊天、大笑。几个人画在一张图里就用 `mm split` 切开，各自演、错开几帧。
- **节奏**：开场已在半空 → 0.08 秒落地深蹲 → 0.5 秒站起 → 0.45 秒东西飞进来 → 0.72 秒吓一跳（第二个人晚 2–3 帧）→ 1.6 秒聊天 → 2.6 秒大笑。

## carrier-reveal 载体带出来（卷帘门男孩）
- **故事**：画印在会动的东西上，被它带进画面（门拉下来、灯箱亮起、横幅放下），一路有小表情，到位后来一个反应。
- **适合**：打烊、开业倒计时、「明天见」、节日装饰。
- **场景**：卷帘门（要关、开两张同角度底图）。
- **素材**：脸的 3–4 个表情（平静、眨眼、眯眼、坏笑）。
- **节奏**：开场门已经下来 1/3 → 匀速下降 2.8 秒（最后 15% 减速），一路眨眼两次、眯眼 → 到底后 0.1 秒坏笑。
- **关键参数**：`"carrier": {"open": "base_open.png", "dur": 2.8, "startAt": 0.33, "ease": "linear"}`

---

## 套模板的步骤
1. `mm new <模板> 场景/`：复制配置，列出需要的素材文件名。
2. 照 `base-prompts.md` 出素材：
   - 先出一张基础角色，其余姿势都以它为底图改。
   - 转折处补中间画：把前后两张一起给 AI，让它画正中间那张。
3. 换底图，填 `surface`（找四角），调 `place`。
4. 改字：`text.lines`。
5. 时间：要更快或更慢，就同比例改所有 `at`、`dur`。不要只改一处，节奏会散。
6. `mm build` → 看 `check_place.png` → `mm preview` → `mm render`。

## 下面 4 个是第二批，临摹自 Higgsfield × clovestudio 宣传片（10/13）

## splash-reveal 泼溅铺开 → 「…」→ 字标弹出（whisk）
- **故事**：产品从上面掉进橱窗、一歪，里面的东西泼到玻璃上铺开往下流；停一下出「…」，像对方正在输入；字标整个弹出。
- **适合**：饮品、甜品、酱料、颜料，一切「会洒」的东西。
- **素材**：产品图（白底）、泼溅最终形状（白底，宽片 + 往下的滴）、字标、`dots.png`（模板自带）。
- **节奏**：空 0.3 秒 → 0.1 秒掉进来，歪 13° → 0.5 秒起泼溅从杯口往外铺（`draw` + `seed` 放杯口、`ease: "ease-out"`，1.8 秒，滴越流越慢）→ 2.34 秒「…」→ 2.5 秒字标 `popin` → 小字打出。
- 泼溅放在产品**下面一层**（graphics 里写在前面）。

## carrier-hop 载体自己憋劲、弹跳（sono 纸袋）
- **故事**：手里捧着的袋子 / 盒子掉进来 → 慢慢往下缩（憋 0.5 秒）→ 弹起 → 落回，印的角色换表情 → 第二次跳得更高还转一下 → 眨眼。
- **适合**：包装、外卖袋、礼盒、杯子；logo 印在上面，不另外出字。
- **素材**：产品三张（平常 / 惊讶 / 眨眼，**先让 AI 把产品改成黑底**再出表情版，白产品在浅底上抠不干净）；底图两张：
  1. 让 AI 把产品放进人手里（「拿着产品」，手指扣住产品下角）；
  2. 再从这张去掉产品、手保持同样的姿势（「同姿势空手」，当底图）。
  然后 `mm hold 拿着.jpg 空手.jpg`：算出产品的 `place` 和压在产品前面的手指遮罩 `front.png`（mask 写 `invert: true`）。
  **不要直接拿「空手捧着」的照片加整只手的遮罩**：手掌会挡在产品前面，看着像产品插进手里，不像被托着（10/13 踩过）。
- **节奏**：0.02 秒掉进来（0.16 秒落定）→ 0.7–1.2 秒压扁到 0.8 → 1.2–1.76 秒第一跳 → 1.85 秒换表情 → 2.3–2.95 秒第二跳带 ±10° 旋转 → 3.45 秒眨眼。落地写 `{"do": "impact", "at": 秒, "sfx": "knock"}`。

## body-to-word 身体变成字（knead）
- **故事**：角色从窗台线「嗖」地弹上来 → 惊讶地看手里的东西 → 字母一个个弹出，**顶替它的身体** → 看镜头 → 一直喝 / 吃到结尾。
- **适合**：有半身像的 IP、吉祥物；字标就是它的身体。
- **素材**：带身体的两张（进场笑、惊讶）+ 去掉身体只留头和手的两张（看镜头、循环动作），同一张底图改，位置对齐；字标。
- **节奏**：0.07 秒弹起（`peek` 快参数：`rise 0.72, riseDur 0.13, hold 0.07, popDur 0.1`）→ 0.27 秒惊讶 → 0.67 秒起字母每 0.09 秒一个 → 1.0 秒身体消失 → 1.53 秒开始循环 → 2.07 秒小字（每字 0.03 秒）。
- 白色窗贴类用 `mm decal` 转透明底，**加 `--keep-margin`**（默认会裁掉四周空白，几张姿势就对不齐了）；脸要保留黑色时用原图（被包住的黑色会留下），脸没封口就借另一张同底图姿势的脸部区域补上。

## slow-fast-letters 字母先慢后快 + 角色掉进来（good company）
- **故事**：第一个词一个字母一个字母慢慢弹（让人看清在拼字）→ 角色从角落掉进来、甩头 → 第二个词一口气弹完 → 小字。
- **适合**：两个词的店名、手写字标、线稿角色。
- **素材**：字标（字母要分开；连笔的先让 AI 重出一张字母分开的，不行就在修图软件里沿最细处切开、留一条透明缝）、角色 3–4 个姿势。
- **节奏**：第一个词每个字母 0.17 秒 → 0.72 秒角色掉进来（0.27 秒落地）→ 1.1–1.45 秒甩头（旋转 ±7°）→ 1.67 秒第二个词每个 0.08 秒 → 2.07 / 2.73 秒小字。

## 下面 4 个是第三批，来自「往栏目包装扩」的临摹（10/14–10/15）

## flipbook 翻页跑酷（参考：贴纸小人跑过一连串场景）
- **故事**：角色原地做一个循环动作（跑、走、跳、骑车），背景每 0.2 秒换一张实拍，像翻页书——一个角色「跑遍全城」。
- **适合**：连锁门店、外卖「哪儿都送」、IP 打卡、城市活动、「一天跑了多少地方」。
- **素材**：5 张背景（竖屏实拍，场景、色调可以完全不同）+ 同一角色 5 张循环姿势（白描边贴纸，配色固定，靠它把整条串起来）。姿势按「每张姿势画在一张和底图一样大的透明画布上、脚底线对齐」放好。
- **节奏**：`baseHold: 6`（每 6 帧换背景）配 `{"do": "cycle", "frames": 6}`（每 6 帧换姿势），两者同步；5×5 一圈 1 秒。想更顺用 4 帧，更「手作」用 8 帧。
- **关键参数**：`"bases": ["bg1.png", …]`、`"baseHold": 6`；角色 `enter: static`、`fit: "art"`、`place` 宽高都是 1。

## color-panels 色块转场包装（参考：「THIS IS WHAT WE DO」色块片头）——全屏图形，不用底图
- **故事**：开场 2×2 色块 + 一行行大字 → 色块和字依次往下掉 → 每段一块颜色板从顶上推下来，带进标题和图标，图标各自演一个小动作 → 收尾色块掉回原位拼回开场（可无缝循环）。
- **适合**：栏目片头、品牌「我们做什么」、服务清单、课程目录、频道 ID。
- **怎么用**：建一个文件夹放 `package.json`（模板在 `assets/packages/color-panels/package.json`），然后 `mm package 文件夹/`：
  - `palette` 4 色（左上、右上、左下、右下）、`ink` 字和图标颜色、`font`；
  - `intro` 开场 1–5 行字；
  - `segments` 每段 `title`（`|` 分两行）+ `icon`：内置 `video` `photo` `bulb` `team`（各自带逐帧量过的小动作），或者一张自己的 PNG（滑进来、弹一下、晃两下）；
  - `segDur` 每段时长，默认 1.9 秒。
- 画面固定 1080×1920 竖屏。音效自动配：出字 pop、推板 whoosh、图标主动作、收尾落地；模板 `package.json` 里声明了 `"sound": "full"`（推板声是它的节奏，别改成 minimal）。

## scribble-pop 线条变出角色、在实拍里跳来跳去（参考：实拍里的 2D 怪物）
- **故事**：几道粗线在场景里甩出弧线、啪地溅开、聚成一团 → 砰地弹成角色、悬停在半空 → 跳到桌面（或任何真实表面）压扁 → 蹦几步 → 朝场景里的人招手。
- **适合**：IP 出场、「我们的吉祥物来了」、品牌角色闯进办公室 / 店里 / 客户现场。
- **素材**：一张实拍底图（有一块能站的表面，比如桌面、台面、地面）+ 同一角色 6 张姿势：炸开、飘、跳、落地压扁、站、招手（基础图 + 图生图逐个改，灰底）。
- **怎么用**：`mm new scribble-pop 场景/`（拷的是 `params.json` 和 `make_scene.py`），改 `params.json`（全是画面像素坐标，用 `mm grid 场景/base.jpg` 量，刻度会自动按 params.json 的 size）：
  - `desk_y` 表面线；
  - `gather` 线条聚拢、角色出现的点；`float` 悬停的位置，别挡住场景里人的脸；
  - `land_x` 落点；`hops` 每一步蹦到的 x 和高度；
  - `desk_height` / `float_height` 在表面上和悬停时角色多高（悬停离镜头近，画大一点）。
  然后 `mm build 场景/`：会先自动跑 `make_scene.py`，按 `params.json` 生成 scene.json 和姿势图，再 `mm preview` / `mm render`。之后改了 `params.json` 或姿势图，再 `mm build` 一次就会重新生成；手改的 scene.json 会被盖掉，位置只改 `params.json`（想手动跑：`uv run 场景/make_scene.py 场景/`）。
- **节奏**：线条 0.06–0.5 秒 → 0.56 秒弹大（过冲）→ 悬停到 0.94 → 0.98–1.08 秒跳到表面 → 每 0.24 秒蹦一步 → 招手。

## street-crowd 街头混入（参考：街头一群 2D 怪物）——实拍街景 + 一群平面小怪，镜头在动
- **故事**：镜头慢慢横移 → 一只大怪从近处楼后探出来（被近处的楼、树、灯杆挡住，像站在远处街上）、眨眼 → 两三只小怪混在行人里往斑马线深处走 → 配角站在真实的东西上点头 → 切到落款镜：镜头往上摇，大怪缩回楼后，店名字标在空出来的天上弹出。
- **适合**：品牌 IP「来到城市里」、开业、城市活动、新系列上街；任何「我们的角色就在你身边」的主题。
- **一个镜头 2–2.5 秒**（原片的节奏）。客户要 5 秒，就拆成两个镜头硬切：街头镜 2.2 秒 + 落款镜 2.25 秒（同一条底片的前后两段，`mm concat` 拼）。别把一个镜头拉到 5 秒，后半段会变成静帧。
- **开始**：每个镜头一个文件夹，`mm new street-crowd 镜1/`，`mm package 镜1/ --name 镜1`，最后 `mm concat 成片.mp4 镜1/镜1.mp4 镜2/镜2.mp4`。
- **每个镜头文件夹各有一份素材**：`mm package` 只认镜头文件夹里的文件。底片、底图、遮挡层每镜各做一次；角色图 `sp/` 可以共用（第 7 步）。

### 素材（按顺序做）
1. **街景**（Midjourney 这类出片感强的生图工具，提示词见 `base-prompts.md`「街景」）：**原片构图**——站在路口一角，近处一栋楼占画面一侧、被画面边裁掉，中间一块天，远处有树、灯杆、远楼，斑马线斜穿。
   - 「低楼大天空」只当备选：大怪没有东西挡，会显得小、像气球。
2. **去近景图**（能照原图改的改图模型，比如 Nano Banana Pro；参考图就是上一张空街景）：去掉近处的楼、红绿灯杆、树、灯杆，背景自然补上。先存着，第 4 步用。
3. **真人走动底片**：改图模型把 2–3 个背影行人画进空街景（约 0.3 画高，**人之间留出一个小怪的宽度**）→ 用你手上的图生视频工具（海螺 H3、Seedance 都行），固定机位、首帧 = 这张图 → 按秒数拆成两镜：
   - 街头镜：`mm plate 视频.mp4 --out 镜1/ --dur 2.2`
   - 落款镜：`mm plate 视频.mp4 --out 镜2/ --start-sec 2.2 --dur 2.25 --width 2400`（接着上一镜往后取；要往上摇，底图出宽一点、高才够）
   - `--dur` 是这一镜取几秒，`--start-sec` 从第几秒开始，都会按视频自己的帧率换算成帧数，24、25、30 帧的视频都照这样写。
   - 会写出 `plate/f_###.jpg`、`base.jpg`、`sky.png`（+ `sky_check.jpg`）、逐帧行人遮罩 `plate/p_###.png`（楼后的东西自动退到行人后面）、`plate/plate.json`（帧率）。`package.json` 的 `duration` 不能超过这一段的秒数。
4. **近处遮挡层**（一定放在 `mm plate` 之后：要对齐到它写出的 `base.jpg`）：
   `mm occluder 空街景.png 去近景.jpg --target 镜1/base.jpg --out 镜1/near.png` → 近处遮挡层 + `near_check.jpg`（粉色 = 挡在大怪前面的东西，**必看**）。落款镜再跑一次：`--target 镜2/base.jpg --out 镜2/near.png`。
   - 原图一定用**没加行人的空街景**（行人会走开，不能算进静态遮挡）。
   - 漏了一块调小 `--diff`，远楼被算进来调大。
   - 遮挡层必须和这一镜的 `base.jpg` 一样大，不能拿别的镜头的 `near.png` 来用，也别去掉 `--target`：大小不对时角色会被挡错位置，自检图上还看不出来。
5. **角色表**（GPT Image 这类平涂干净的生图模型，灰底，提示词见 `base-prompts.md`）：
   - 走路的两只：**3/4 侧面能看到脸**、面条手脚、大步。验收：第 1、3 张前后脚距离 ≥ 身高 0.3；纯背影不过关，重出。
   - 大怪：上半身、**3/4 侧身往下看街**、一只手扣着东西（楼顶、墙角），**不挥手**；眼睛圆、睁开（眨眼要用）。
   - 配角 5–6 个，剪影各不一样。
   - `mm cutout 表.png --names … --out 镜1/sp`，看 `表名_check.jpg` 对号。
6. **落款字标**：生图模型出黑底白字的字标 → `mm decal 字标原图.png --color 和天空对比的颜色 --out 镜1/sp/wordmark.png`（自动裁掉四周空白）→ `title.img`。系统字只当兜底。
7. **落款镜共用角色图**：`ln -s ../镜1/sp 镜2/sp`（软链接，`mm package` 认），或者整份拷一份 `cp -R 镜1/sp 镜2/`。

### 落款镜清单（镜2）
落款镜的底片起点不同、底图更宽，镜1 的东西不能直接搬过去：
1. `mm new street-crowd 镜2/`
2. `mm plate 视频.mp4 --out 镜2/ --start-sec 2.2 --dur 2.25 --width 2400`（新起点、底图 2400 宽）
3. `mm occluder 空街景.png 去近景.jpg --target 镜2/base.jpg --out 镜2/near.png`（再跑一次，对齐到镜2 的底图）
4. `sp`：第 7 步的软链接或拷贝
5. **坐标在 `镜2/base.jpg` 上重新量**（`mm grid 镜2/base.jpg`）：底图从 1990 宽变成 2400 宽，约 ×1.2，镜1 的 `camera`、角色的 `x` `y` `h` 直接抄过来会全部错位。
6. `duration` 写 2.25（不超过这段底片）；`camera` 往上摇（y 变小）；大怪写 `exit` 缩回楼后，空出来的天给 `title`。

### package.json 字段（坐标全是底图原像素，用 `mm grid 镜1/base.jpg --keep` 看；`--keep` 就是按原像素标刻度）
| 字段 | 说明 |
|---|---|
| `size` `fps` | 画面尺寸（默认 1920×1080）、帧率（默认 24） |
| `duration` | 秒数。**不能超过底片长度**（渲染前检查会拦） |
| `base` `plate` `sky` `near` | 底图、底片帧文件夹、天空遮罩、近处遮挡层。有 `near` 时楼后的东西按近处遮挡算（推荐）；没有就只露在天空里 |
| `camera` | `{"from": [x, y, 宽], "to": [x, y, 宽], "at": 0, "dur": 秒, "ease": "linear"/"smooth"}`。底图上的取景框，高 = 宽 × 9/16。横移：1.85 秒约 60px；往上摇：y 变小（落款镜 1.2 秒摇 260px、smooth）。**框不能出底图**（渲染前检查会拦） |
| `actors[]` | 每个角色一条，见下表 |
| `title` | `{"img": "sp/wordmark.png" 或 "text": ["大字", "小字"], "at": 秒, "hold": 秒, "pos": [x, y], "size": 0.14}`，见下面「落款」 |
| `sound` | 模板里写的是 `full`。包装模板各自在 `package.json` 里声明默认档位（street-crowd、color-panels 都是 `full`）；场景模板默认 `minimal`。大怪探出 / 缩回的 whoosh 是主事件声，改成 `minimal` 会把它去掉；`--sound` 临时改 |

**落款 `title`**：
- `at` = 出场时刻；不写 `at` 时 = `duration` − `hold`（`hold` 默认 1.2 秒）。
- `img` 整张一起弹出；`text` 每行错开 0.1 秒弹出。都是 0.28 秒弹出、过冲 16%。
- `pos` 第一行中心在画面上的比例位置（默认 `[0.5, 0.2]`）；`size` 第一行的高占画高的比例（默认 0.11）。
- 只对 `text` 有用：`color` 字色（默认白）、`font` 字体、`weight` 粗细（默认 800）、`small` 第二行起相对第一行的大小（默认 0.42）。

actors 通用字段：`img`、`x` `y`（锚点，默认脚底中点；浮着的是中心）、`h`（身高）、`anchor`、`flip`、`phase`（小动作错开）、`shadow: false`（站在地上的默认有影子）、`sway`（左右轻轻摆的幅度，弧度，大怪用 0.02）。
- `enter`：`{"from": [dx, dy], "at": 秒, "dur": 秒, "ease": …}`，从偏开 `[dx, dy]` 的地方移到原位；`dur` 默认 0.55，`ease` 默认 `"ease-out"`（先快后慢）。
- `exit`：`{"to": [dx, dy], "at": 秒, "dur": 秒, "ease": …}`，移开 `[dx, dy]`，退完就不画了；`dur` 默认 0.45，`ease` 默认 `"ease-in"`（先慢后快）。
- `ease` 可选 `"linear"`（匀速）、`"smooth"`（两头慢）、`"ease-out"`、`"ease-in"`。
- `blink`：`{"eye": [[x, y, r], …], "at": [秒, …], "color": "#rrggbb"}`。`at` 默认 `[1.1]`；`color` 是眼皮颜色，默认取眼睛正上方一圈毛的颜色，取得不对（眨眼时出现一块色斑）再手写。
- `idle`：`"nod"` 点头、`"float"` 浮着（`amp` 上下浮多少像素，默认 9）；不写就不动。
- `appear`（**不推荐**）：`"appear": 秒`，到点凭空弹出来。出场要有来由，不推荐用 `appear` 填空档，它也不算进「X–Y 秒没有新事件」的空档检查。

| 类型 | 写法 | 说明 |
|---|---|---|
| 楼后大怪 | `"behind": true, "enter": {"from": [420, 0], "at": 0.1, "dur": 0.5}, "sway": 0.02, "blink": {"eye": [[x,y,r], [x,y,r]], "at": [1.2]}` | 被 `near`（近处的楼、树、灯杆）和行人挡住。`enter.from` 要够大，开头完全藏在楼后（自检会提醒露太少）。`eye` 是**角色图里**每只眼的圆心和半径（`mm grid sp/大怪.png --keep` 量） |
| 缩回去 | `"exit": {"to": [560, 260], "at": 0.6, "dur": 0.4}` | 相对位移、先慢后快，退完就不画了。落款镜用：大怪缩回楼后，天空空出来给字标 |
| 从楼后探出的小配角 | `"behind": true, "enter": {"from": [110, 0], "at": 1.6, "dur": 0.4}` | 第二个「探出来」的事件，填中段 |
| 远处的配角 | `"behind": "people", "idle": "nod"` | 站在对面人行道上的：只被走过的行人挡住，不会画到人身上 |
| 近处的配角 | `"idle": "nod"`（不写 behind） | 站在信号箱上、路沿上，画在最前面 |
| 浮着的 | `"idle": "float", "amp": 9` | 最多 2 个 |
| 走路的 | `"walk": [4 张图], "from": [x, 脚底y, 身高], "to": [x, 脚底y, 身高], "at", "until", "after": "stop"/"exit"` | 见下面「走路」 |

**走路**：
- `at` 开始走，`until` 走到 `to` 的时刻（不是「走多久」，要比 `at` 大）；不写 `until` 就走满整段。位置和身高一起从 `from` 变到 `to`，走远变小。
- 走到以后：`"after": "stop"`（默认）站住，换回第 1 张、不再颠；`"after": "exit"` 按 `from` → `to` 的方向和速度接着走。往深处走的会越走越小，不会离开画面；要它走出画面，就让 `to` 指向画面边。身高缩到 `to` 身高的 40% 以下就不再画；缩没了或走出画面，脚步声也停。
- 手感（一般不用改）：`step` 每张姿势停几帧（默认 3）、`bob` 每步颠多高（身高的比例，默认 0.06）、`squash` 落地压扁多少（默认 0.07）、`sway` 往迈步那侧歪多少（弧度，默认 0.09，约 5°）。

### 摆位规矩
- **大怪**：脸在天空里、一只手扣在远楼楼顶上，身子藏在近处的树和楼后面；画面上沿裁掉一点头顶没关系（原片就是）。灯杆、红绿灯挡在它前面最有纵深感。
- **小怪**：夹在行人之间或站在旁边人的外侧，脚比旁边的人略低一点（更靠前），身高约人的 0.6–0.8；走向往消失点收。
- **配角**站在真实的东西上（信号箱顶、路沿、对面人行道、长椅），分远、中、近三层；远的写 `behind: "people"`。
- **落款**放在空的天上（街头镜里天被大怪占着，就在落款镜里让大怪缩回去），自检会提醒「落款压在…上」。
- **每 0.8 秒内要有一个看得见的新事件**（`mm package` 会提醒空档）：大怪探出 / 缩回、眨眼、第二只探出来、小怪走进或走出画面、落款。持续走路不算。出场要有来由，不推荐用 `appear` 凭空弹出配角填中段。

### 自检
- `mm package` 每次出 3 张 `名字_check_t*.jpg`：粉 = 近处遮挡（没有 near 时青 = 天空），每个角色和落款画框；`提醒` 里有字先改。
- 渲染前检查：镜头框出底图、时长超过底片、遮罩和底图宽高比例对不上、楼后角色没有遮罩（near / sky 都没有）、走路角色的 from / to / until 写错——有一条就不渲染，并用中文说明怎么改。
- 抽帧看动作：`mm frames 成片.mp4 --from 0 --to 2 --n 12`。
