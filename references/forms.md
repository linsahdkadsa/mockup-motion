# 形式：载体联动、点缀，以及「配件」材质

> 主流程只用：载体联动（卷帘门）、遮罩（圆窗）、少量点缀（热气、小卷线、对话气泡）。
> 下面的材质（霓虹、立体字、LED、粉笔、贴纸边）和花哨点缀是「配件」：只有小故事真的需要时才用，不要为了展示而展示。

同一个 logo 换一种「形式」，就是完全不同的一段。形式写在每块图形的 `look`、`carrier`、`accents` 里。

## 材质 look.style
| style | 看起来像 | 适合的场景 | 常配的动法 | 参数 |
|---|---|---|---|---|
| `print`（默认） | 油漆、印刷 | 招牌、海报、纸袋、卷帘门 | 什么都行 | `blend: multiply` 让纸纹、布纹透出来 |
| `neon` | 霓虹灯管，带光晕，会照亮墙面 | 夜景砖墙、酒吧 | `flicker` 逐个通电；`draw` 加 `tip` 像光在描 | `color` 灯管颜色，`glow` 光晕大小 |
| `extrude` | 立体字，有厚度，墙上有投影 | 前台墙、外立面 | `bounce` 一个个落下，配 `shine` 扫光 | `depth` 厚度，`dir` 投影方向，`side` 侧面颜色，`sheen` 金属高光 0–1，`shadow` 投影深浅 |
| `sticker` | 带白边的贴纸，有一点阴影 | 玻璃橱窗、笔记本、箱子 | `peel` 撕贴、`drop` | `border` 白边宽度，`borderColor` 白边颜色 |
| `led` | LED 点阵屏，会发光 | 户外大屏、地铁屏 | `pixels` 像素拼出、`type` 加 `cursor` | `cell` 一个灯珠多大（图形像素） |
| `chalk` | 粉笔字，有颗粒、不均匀 | 黑板、水泥地 | `write`、`draw` | 通常配 `color: "#f1efe6"` |

所有材质都能用 `color` 把图形整体换成一种颜色。深色 logo 放到黑板、霓虹、LED 上时一定要换成亮色。

## 遮罩 mask（吸收自 Codex）
圆窗、拱门、任意形状的边框：图形只在遮罩里显示，从边框后面探出来才像真的。
```json
"mask": {"ellipse": [cx, cy, rx, ry]}        // 也可以 {"rect": [x0,y0,x1,y1], "radius": 40} / {"polygon": [[x,y],...]} / {"image": "mask.png"}
```
坐标和 `quad` 一样，按缩放后的输出尺寸算（`mm grid` 网格图上的数字）。`invert: true` 反过来用：遮罩里的部分把图形挡住（比如 `mm hold` 算出的、压在产品前面的手指 `front.png`），`feather` 边缘羽化（默认 1.2 像素）。`surface.quad` 写成遮罩的外接框，peek 从框的边缘探出，遮罩负责把弧形边挡住。`check_place.png` 里红线就是遮罩的边。

## 载体联动 carrier
图形印在会动的东西上，就让载体和图形一起动，不要只移动图形假装载体在动。
- **卷帘门** `{"type": "shutter", "open": "base_open.png", "at": 0.3, "dur": 1.5}`
  - 门从卷帘盒里拉下来，门上的图跟着一起往下走，门下面露出打开状态，落到底咚一声。
  - `quad` 框门帘本身（不含上面的卷帘盒）。
  - 需要一张**门打开的同角度底图**：用图生图把关着的门改成打开，提示词见 `base-prompts.md`。
  - 门上的图一般用 `static`（本来就印在门上），门落到底以后再让别的组做反应。

## 点缀 accents
和品牌有关的小东西，画在图形平面上，所以会跟着透视、也会跟着霓虹发光。
```json
"accents": [{"kind": "sparkle", "group": "ai", "at": 3.0, "n": 3, "color": "#ffffff"}]
```
写 `group` 就放在那组零件附近，也可以直接写 `pos`（图形坐标）。

| kind | 效果 | 适合 | 参数 |
|---|---|---|---|
| `sparkle` | 四角星一闪一闪（AI 的通用符号） | AI、美妆、新品 | `n` 几颗，`size`，`dur` |
| `shine` | 一道光从左扫到右，只扫在图形上 | 立体字、金属、玻璃 | `dur`、`width`、`strength` |
| `steam` | 热气一缕缕往上飘，一直循环 | 咖啡、面、热饮 | `n`、`height`、`period` |
| `burst` | 一圈短线往外炸开 | 盖章、落地、砸下的那一下 | `n`、`size`，颜色一般用图形色 |
| `dust` | 落地烟尘：两边冒白云往外飘 | `splat` `drip` 落地会自动加；`drop` 和别的落地要手动放 | `width`、`n`、`size` |
| `alert` | 头顶冒出三道线（吓一跳） | 角色「先平静再出事」的那一下 | `anchor: [0.6, 0]` 放头顶 |
| `bubble` | 对话气泡，弹出来一直留着 | 角色说话：「hi!」「好香！」 | `text`、`fontSize`、`tail` -1/1 尾巴朝左/右、`ink` 描边色 |
| `hearts` | 爱心往上飘 | 可爱、好吃、喜欢 | `n`、`size`、`rise`（飘多高，角色高度的比例，默认 0.8；上面有字时调小或把 anchor 挪到侧面）|
| `speedlines` | 一侧闪过几道横线 | 冲进来、跑过去 | `dir` -1 线在左 / 1 在右、`dur` |
| `fizz` | 汽水小气泡往上冒，一直循环 | 汽水、啤酒、气泡水 | `n`、`height`、`period` |
| `bulb` | 头顶亮起一个小灯泡 | 想到了、精神了、灵感 | `size`、`fill` 灯泡颜色 |
| `strokes` | 几道粗线「头沿路径走、尾巴跟着」扫过，可带 `splat` 落地溅开 | 从无到有变出角色、能量聚集 | `lines`：每条 `pts`（4 个点，画布比例，三次贝塞尔）、`at`、`dur`、`color`、`width`（画布宽度比例）、`trail`；`splat`：`pos`、`at`、`dur`、`size` |
| `puff` | 呼出一团气，从 `pos` 飘到 `to` 边飘边散 | 「哈～」之后接着出字：字就在 `to` 出现，看起来是说出来的 | `pos`、`to`（图形坐标）、`dur` |

位置：写 `group`（可以写 `"rig"` 表示角色）再加 `anchor: [x比例, y比例]`，比如 `[0.5, 0]` 是那组的正上方，`[1, 0.4]` 是右侧偏上。

组本身的点缀开关：
- `draw` / `write` 加 `tip: true`：发光笔头跟着画到的地方走（`tipColor`、`tipSize`）
- `type` 加 `cursor: true`：打字光标，打完再闪几下（`cursorColor`）
